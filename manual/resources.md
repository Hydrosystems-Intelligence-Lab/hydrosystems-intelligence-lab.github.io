## Purpose

This page collects links to useful tutorials, internal notes, and reference material. As the group grows, it can also point to blog posts or short technical notes written by HORA members.

## Starter Resource Categories

- Hydrologic modeling
- Remote sensing and Earth observation
- Hydroclimate extremes
- Lake and reservoir dynamics
- Water equity and infrastructure access
- Scientific Python and R
- Git and GitHub
- Reproducible research
- Writing and publication
- Fellowships and job searches

## Adding a Resource

When adding a resource, include a one-sentence note explaining why it is useful. A long list of unexplained links is hard to maintain.

Suggested format:

```markdown
- [Resource title](https://example.com): Short note about why this is useful.
```
